# P6d Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Editors give each person a photo, shown on the polaroid card and at the top of the profile. The photo goes to Cloudinary through a signed upload and is saved as an ordinary, undoable `updatePerson` op.

**Architecture:**
- **Shared** gets `Person.photo` (`{ publicId, version }`), a helper that finds every photo an op sets, and two error codes.
- **The API** talks to Cloudinary only through a small `PhotoStore` interface:
  - the real one wraps the official `cloudinary` SDK;
  - a memory one serves the tests and the e2e server.
- **The API's photo duties:**
  - it signs uploads into `<folder>/clans/<clanId>/people/<personId>/<16 hex>`;
  - it verifies every op that sets a photo;
  - it deletes a clan's photos with the clan.
- **The web upload path:** shrink the photo in the browser, ask the API for a signature, upload straight to Cloudinary with progress, then save through the existing change runner, so the "Đã đổi: …" toast and its Undo come for free.

**Tech Stack:** Zod 4, Express 5 and Mongoose, the `cloudinary` Node SDK (v2 API), React 19, TanStack-free plain `apiRequest`, `XMLHttpRequest` (for upload progress), Vitest with jsdom, Playwright.

## Global Constraints

- **Specs.** Spec §7.6 "Photo" and §12 "Image storage (Cloudinary)" in `docs/superpowers/specs/2026-11-11-ancestors-tree-design.md`, mirrored in `.vi.md`. Any design change updates **both** spec files in the same commit.
- **Size limit.** At most 2 MB = `2 * 1024 * 1024` bytes (`MAX_PHOTO_BYTES`), checked after the browser shrinks the photo.
- **Formats.** jpg, png and webp only (`image/jpeg`, `image/png`, `image/webp`). The signed upload sends `allowed_formats=jpg,png,webp`.
- **Shrinking.** The browser scales to at most 1600 px on the long side, then encodes WebP at quality 0.85, or JPEG at 0.85 when WebP encoding is unavailable.
- **Path.** `<CLOUDINARY_FOLDER>/clans/<clanId>/people/<personId>/<random>`, where `<random>` is 16 lowercase hex characters (`randomBytes(8).toString('hex')`). The path holds no names.
- **Signed parameters,** exactly:
  - `public_id` (the full path);
  - `asset_folder` (the path without its last segment);
  - `allowed_formats=jpg,png,webp`;
  - `tags=clan_<clanId>`;
  - `transformation=c_limit,w_1600,h_1600`;
  - `timestamp`.
- **Delivery transformations:**
  - card `c_fill,g_face,w_172,h_148,f_auto,q_auto`;
  - profile `c_fill,g_face,w_480,h_480,f_auto,q_auto`;
  - URL `https://res.cloudinary.com/<cloud>/image/upload/<transformation>/v<version>/<publicId>`.
- **Verification.** Every op that sets a photo is verified, including undo, redo, revert, `addPerson` and `restorePerson`. The rules:
  - the `publicId` starts with `<folder>/clans/<clanId>/people/<personId>/`;
  - the asset exists;
  - its `bytes` are at most `MAX_PHOTO_BYTES`;
  - its `version` equals the op's `version`.
  - Otherwise the server answers `PHOTO_REJECTED` (422).
- **Deleting bad photos.** The server deletes an asset only when it is inside that prefix and too large.
- **Not configured.** When `CLOUDINARY_URL` is missing:
  - the signing route answers `PHOTOS_NOT_CONFIGURED` (503);
  - an op that sets a photo answers `PHOTO_REJECTED` (422), never a 5xx, because the web's send queue retries 5xx forever.
- **Deleting a clan** deletes the prefix `<folder>/clans/<clanId>/` after the database transaction. A Cloudinary failure is logged and never fails the request.
- **Web without photos.** Without `VITE_CLOUDINARY_CLOUD_NAME`, the web shows initials and hides "Đổi ảnh" and "Gỡ ảnh".
- **CSP** (`netlify.toml`): `img-src` adds `https://res.cloudinary.com`; `connect-src` adds `https://api.cloudinary.com`.
- **Secrets.**
  - Never read, print or edit `apps/api/.env`.
  - No credential-shaped literals in tests or docs. Build any `cloudinary://…` test string from variables (`` `cloudinary://${KEY}:${SECRET}@${CLOUD}` ``) and never write one as a literal.
  - Fake e-mail addresses use `example.test`.
- **Language.** Code, comments and docs are in English. VI strings are natural Vietnamese. No count plurals (one i18n form per message).
- **Commits.** TDD: watch each new test fail before writing the code. Use `rtk` before git commands and plain `pnpm` for scripts. Commit through a message file (`git commit -F <file>`), and end every message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Before each commit,** run the covering tests. Run `pnpm check` (format, lint, typecheck, tests with coverage, the error-code docs check, build) in the last task.

`packages/shared/src/tree/photos.ts`:

```ts
import type { Op, SingleOp } from './ops.ts';
import type { PersonPhoto } from './schemas.ts';

export interface PhotoInOp {
  personId: string;
  photo: PersonPhoto;
}

function fromSingle(op: SingleOp): PhotoInOp[] {
  switch (op.type) {
    case 'addPerson':
      return op.payload.photo ? [{ personId: op.payload.id, photo: op.payload.photo }] : [];
    case 'updatePerson': {
      const photo = op.payload.changes.photo;
      return photo ? [{ personId: op.payload.id, photo }] : [];
    }
    case 'restorePerson': {
      const { person } = op.payload;
      return person.photo ? [{ personId: person.id, photo: person.photo }] : [];
    }
    default:
      return [];
  }
}

/** Every photo an op sets, so the server can check each one (spec §12, verified on save). */
export function photosInOp(op: Op): PhotoInOp[] {
  return op.type === 'batch' ? op.payload.ops.flatMap(fromSingle) : fromSingle(op);
}
```

`apps/api/src/photos/cloudinary.test.ts`. No network: it checks the URL parsing and the signature against Cloudinary's documented SHA-1 rule, which is the sorted `key=value` pairs joined with `&`, followed by the secret.

```ts
import { createHash } from 'node:crypto';
import { describe, expect, it } from 'vitest';
import { createCloudinaryPhotoStore, parseCloudinaryUrl } from './cloudinary.ts';

const KEY = 'key123';
const SECRET = 'secret456';
const CLOUD = 'demo-cloud';
const URL_FROM_PARTS = `cloudinary://${KEY}:${SECRET}@${CLOUD}`;

describe('parseCloudinaryUrl', () => {
  it('reads the key, secret and cloud name', () => {
    expect(parseCloudinaryUrl(URL_FROM_PARTS)).toEqual({
      cloudName: CLOUD,
      apiKey: KEY,
      apiSecret: SECRET,
    });
  });

  it('refuses anything else without echoing it', () => {
    expect(() => parseCloudinaryUrl(`https://${SECRET}@x`)).toThrow(/CLOUDINARY_URL/);
    expect(() => parseCloudinaryUrl(`https://${SECRET}@x`)).not.toThrow(new RegExp(SECRET));
  });
});

describe('createCloudinaryPhotoStore().signUpload', () => {
  it('signs every upload parameter with the API secret', () => {
    const store = createCloudinaryPhotoStore({ url: URL_FROM_PARTS, folder: 'ancestors-tree/test' });
    const publicId = 'ancestors-tree/test/clans/c1/people/p1/0123456789abcdef';
    const { url, fields } = store.signUpload(publicId, 'c1');
    expect(url).toBe(`https://api.cloudinary.com/v1_1/${CLOUD}/image/upload`);
    expect(fields.api_key).toBe(KEY);
    const { signature, api_key: _key, ...signed } = fields;
    const toSign = Object.keys(signed)
      .sort()
      .map((name) => `${name}=${signed[name]}`)
      .join('&');
    expect(signature).toBe(createHash('sha1').update(toSign + SECRET).digest('hex'));
    expect(signed).toMatchObject({
      public_id: publicId,
      asset_folder: 'ancestors-tree/test/clans/c1/people/p1',
      allowed_formats: 'jpg,png,webp',
      tags: 'clan_c1',
```

```ts
export interface SignedUpload {
  url: string;
  fields: Record<string, string>;
}

export interface PhotoAsset {
  bytes: number;
  version: number;
}

/** Everything the API asks of the image host. The real one is Cloudinary (cloudinary.ts). */
export interface PhotoStore {
  /** CLOUDINARY_FOLDER, e.g. ancestors-tree/dev. */
  readonly folder: string;
  signUpload(publicId: string, clanId: string): SignedUpload;
  /** Null when the asset does not exist. */
  inspect(publicId: string): Promise<PhotoAsset | null>;
  destroy(publicId: string): Promise<void>;
  deletePrefix(prefix: string): Promise<void>;
}

/** The parameters every upload is signed with (spec §12), besides api_key and signature. */
export function uploadParameters(publicId: string, clanId: string): Record<string, string> {
  return {
    public_id: publicId,
    asset_folder: publicId.slice(0, publicId.lastIndexOf('/')),
    allowed_formats: 'jpg,png,webp',
    tags: `clan_${clanId}`,
    transformation: 'c_limit,w_1600,h_1600',
  };
}

export interface MemoryPhotoStore extends PhotoStore {
  put(publicId: string, asset: PhotoAsset): void;
  has(publicId: string): boolean;
  readonly deletedPrefixes: string[];
}

/**
 * For tests and the e2e server: assets live in a Map. `assumeUploaded` answers every unknown id
 * as that asset, because the e2e browser's upload never reaches this process.
 */
export function createMemoryPhotoStore(
  options: { folder?: string; assumeUploaded?: PhotoAsset } = {},
): MemoryPhotoStore {
  const assets = new Map<string, PhotoAsset>();
  const deletedPrefixes: string[] = [];
  return {
    folder: options.folder ?? 'ancestors-tree/test',
    deletedPrefixes,
    signUpload(publicId, clanId) {
      return {
        url: 'https://api.cloudinary.com/v1_1/memory/image/upload',
        fields: {
          ...uploadParameters(publicId, clanId),
          timestamp: '0',
          api_key: 'memory',
          signature: 'memory',
        },
      };
    },
    inspect(publicId) {
      return Promise.resolve(assets.get(publicId) ?? options.assumeUploaded ?? null);
    },
    destroy(publicId) {
      assets.delete(publicId);
      return Promise.resolve();
    },
    deletePrefix(prefix) {
      deletedPrefixes.push(prefix);
      for (const id of [...assets.keys()]) if (id.startsWith(prefix)) assets.delete(id);
      return Promise.resolve();
    },
    put(publicId, asset) {
      assets.set(publicId, asset);
    },
    has(publicId) {
      return assets.has(publicId);
    },
  };
```

```ts
import { v2 as cloudinary } from 'cloudinary';
import { uploadParameters, type PhotoAsset, type PhotoStore } from './store.ts';

const URL_PATTERN = /^cloudinary:\/\/([^:@/]+):([^@/]+)@([\w-]+)$/;
/** delete_resources_by_prefix removes at most 1000 per call; a clan is far smaller. */
const MAX_DELETE_ROUNDS = 50;

export function parseCloudinaryUrl(url: string): {
  cloudName: string;
  apiKey: string;
  apiSecret: string;
} {
  const match = URL_PATTERN.exec(url);
  if (!match?.[1] || !match[2] || !match[3]) {
    // Never echo the value: it holds the API secret.
    throw new Error('CLOUDINARY_URL must look like cloudinary://<api_key>:<api_secret>@<cloud_name>');
  }
  return { apiKey: match[1], apiSecret: match[2], cloudName: match[3] };
}

function httpCode(error: unknown): number | undefined {
  return (error as { error?: { http_code?: number } } | null)?.error?.http_code;
}

/** The real image host (spec §12). Upload signing is local; inspect and delete use the Admin API. */
export function createCloudinaryPhotoStore(options: { url: string; folder: string }): PhotoStore {
  const { cloudName, apiKey, apiSecret } = parseCloudinaryUrl(options.url);
  cloudinary.config({ cloud_name: cloudName, api_key: apiKey, api_secret: apiSecret, secure: true });
  return {
    folder: options.folder,
    signUpload(publicId, clanId) {
      const params = {
        ...uploadParameters(publicId, clanId),
        timestamp: String(Math.floor(Date.now() / 1000)),
      };
      const signature = cloudinary.utils.api_sign_request(params, apiSecret);
      return {
        url: `https://api.cloudinary.com/v1_1/${cloudName}/image/upload`,
        fields: { ...params, api_key: apiKey, signature },
      };
    },
    async inspect(publicId): Promise<PhotoAsset | null> {
      try {
        const resource = (await cloudinary.api.resource(publicId, {
          resource_type: 'image',
          type: 'upload',
        })) as { bytes: number; version: number };
        return { bytes: resource.bytes, version: resource.version };
      } catch (error) {
        if (httpCode(error) === 404) return null;
        throw error;
      }
    },
    async destroy(publicId) {
      await cloudinary.uploader.destroy(publicId, { resource_type: 'image', invalidate: true });
    },
    async deletePrefix(prefix) {
      for (let round = 0; round < MAX_DELETE_ROUNDS; round += 1) {
        const result = (await cloudinary.api.delete_resources_by_prefix(prefix, {
          resource_type: 'image',
          type: 'upload',
        })) as { partial?: boolean };
        if (!result.partial) return;
      }
    },
  };
}
```

```ts
import { MAX_PHOTO_BYTES, photosInOp, type Op } from '@ancestors-tree/shared/tree';
import { AppError } from '../http/AppError.ts';
import { personPhotoPrefix } from './paths.ts';
import type { PhotoStore } from './store.ts';

function reject(message: string): never {
  throw new AppError('PHOTO_REJECTED', message);
}

/**
 * Spec §12, verified on save: every photo an op sets (undo, redo and revert included) must be
 * this person's, exist at that version and weigh at most 2 MB. Runs before the transaction: it
 * calls the image host. An oversized asset inside the person's folder is deleted; nothing
 * outside it ever is.
 */
export async function verifyOpPhotos(
  photos: PhotoStore | undefined,
  clanId: string,
  op: Op,
): Promise<void> {
  const found = photosInOp(op);
  if (found.length === 0) return;
  // A 422, not PHOTOS_NOT_CONFIGURED (503): the web's send queue retries 5xx answers forever.
  if (photos === undefined) reject('Photos are not set up on this server');
  for (const { personId, photo } of found) {
    if (!photo.publicId.startsWith(personPhotoPrefix(photos.folder, clanId, personId))) {
      reject("This photo is not in this person's folder");
    }
    const asset = await photos.inspect(photo.publicId);
    if (asset === null) reject('This photo does not exist');
    if (asset.bytes > MAX_PHOTO_BYTES) {
      await photos.destroy(photo.publicId);
      reject('This photo is larger than 2 MB');
    }
    if (asset.version !== photo.version) reject('This photo has another version');
  }
}
```

```ts
/** Spec §12: jpg, png or webp; shrunk in the browser to 1600 px before the 2 MB check. */
export const PHOTO_TYPES = ['image/jpeg', 'image/png', 'image/webp'] as const;
/** Larger files are refused before decoding: a phone photo is 3–6 MB. */
export const MAX_SOURCE_BYTES = 25 * 1024 * 1024;
export const MAX_PHOTO_SIDE = 1600;
const QUALITY = 0.85;

export type PhotoProblem = 'type' | 'sourceTooLarge' | 'unreadable' | 'tooLarge';

export class PhotoFileError extends Error {
  constructor(readonly problem: PhotoProblem) {
    super(`Photo file problem: ${problem}`);
    this.name = 'PhotoFileError';
  }
}

export function fitWithin(width: number, height: number, max: number) {
  const scale = Math.min(1, max / Math.max(width, height));
  return {
    width: Math.max(1, Math.round(width * scale)),
    height: Math.max(1, Math.round(height * scale)),
  };
}

export function checkSource(file: File): PhotoProblem | null {
  if (!(PHOTO_TYPES as readonly string[]).includes(file.type)) return 'type';
  if (file.size > MAX_SOURCE_BYTES) return 'sourceTooLarge';
  return null;
}

function toBlob(canvas: HTMLCanvasElement, type: string): Promise<Blob | null> {
  return new Promise((resolve) => {
    canvas.toBlob(resolve, type, QUALITY);
  });
}

/**
 * At most 1600 px on the long side, upright (EXIF orientation applied), re-encoded as WebP, or
 * JPEG where the browser cannot encode WebP. A white background keeps transparent PNGs light in
 * JPEG.
 */
export async function shrinkPhoto(file: File): Promise<Blob> {
  let bitmap: ImageBitmap;
  try {
    bitmap = await createImageBitmap(file, { imageOrientation: 'from-image' });
  } catch {
    throw new PhotoFileError('unreadable');
  }
  const { width, height } = fitWithin(bitmap.width, bitmap.height, MAX_PHOTO_SIDE);
  const canvas = document.createElement('canvas');
  canvas.width = width;
  canvas.height = height;
  const context = canvas.getContext('2d');
  if (context === null) {
    bitmap.close();
    throw new PhotoFileError('unreadable');
  }
  context.fillStyle = '#ffffff';
  context.fillRect(0, 0, width, height);
  context.drawImage(bitmap, 0, 0, width, height);
  bitmap.close();
  const webp = await toBlob(canvas, 'image/webp');
  if (webp?.type === 'image/webp') return webp;
  const jpeg = await toBlob(canvas, 'image/jpeg');
  if (jpeg === null) throw new PhotoFileError('unreadable');
  return jpeg;
}
```

```ts
import {
  PhotoUploadResponseSchema,
  type PhotoUploadResponse,
} from '@ancestors-tree/shared';
import type { PersonPhoto } from '@ancestors-tree/shared/tree';
import { z } from 'zod';
import { apiRequest } from '../../shared/lib/apiClient';

export class PhotoUploadError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'PhotoUploadError';
  }
}

const UploadedSchema = z.object({ public_id: z.string(), version: z.number().int().positive() });

export function requestPhotoUpload(clanId: string, personId: string): Promise<PhotoUploadResponse> {
  return apiRequest(`/clans/${clanId}/people/${personId}/photo-upload`, PhotoUploadResponseSchema, {
    method: 'POST',
  });
}

/** Straight to Cloudinary (spec §12). XHR, not fetch: fetch cannot report upload progress. */
export function uploadPhoto(
  target: PhotoUploadResponse,
  file: Blob,
  onProgress: (fraction: number) => void,
  signal?: AbortSignal,
): Promise<PersonPhoto> {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    const form = new FormData();
    for (const [name, value] of Object.entries(target.fields)) form.append(name, value);
    form.append('file', file);
    const abort = () => {
      xhr.abort();
      reject(new DOMException('The upload was cancelled', 'AbortError'));
    };
    if (signal?.aborted) {
      abort();
      return;
    }
    signal?.addEventListener('abort', abort, { once: true });
    xhr.upload.onprogress = (event) => {
      if (event.lengthComputable && event.total > 0) onProgress(event.loaded / event.total);
    };
    xhr.onerror = () => {
      signal?.removeEventListener('abort', abort);
      reject(new PhotoUploadError('The upload did not reach the image host'));
    };
    xhr.onload = () => {
      signal?.removeEventListener('abort', abort);
      let body: unknown;
      try {
        body = JSON.parse(xhr.responseText);
      } catch {
        body = undefined;
      }
      const parsed = UploadedSchema.safeParse(body);
      if (xhr.status < 200 || xhr.status >= 300 || !parsed.success) {
        reject(new PhotoUploadError(`The image host answered ${xhr.status}`));
        return;
      }
      resolve({ publicId: parsed.data.public_id, version: parsed.data.version });
    };
    xhr.open('POST', target.url);
    xhr.send(form);
  });
}
```

```tsx
import { ImageUp, Trash2 } from 'lucide-react';
import { useContext, useEffect, useId, useRef, useState, type ChangeEvent } from 'react';
import { useTranslation } from 'react-i18next';
import { ApiError, errorMessageKey } from '../../shared/lib/apiError';
import { Button } from '../../shared/ui';
import { ChangeContext } from './ChangeRunner';
import { PHOTO_TYPES, PhotoFileError, checkSource, shrinkPhoto } from './photoFile';
import { photosEnabled } from './photoUrl';
import { PhotoUploadError, requestPhotoUpload, uploadPhoto } from './photoUpload';
import { ProfilePhoto } from './ProfilePhoto';

const ICON = { 'aria-hidden': true, className: 'size-4', strokeWidth: 1.75 } as const;

type Work = { kind: 'idle' } | { kind: 'working'; fraction: number } | { kind: 'error'; text: string };

/** The profile's photo with "Đổi ảnh" and "Gỡ ảnh" for editors (spec §7.6 "Photo"). */
export function PhotoControl({ clanId, person }: { clanId: string; person: Person }) {
  const { t } = useTranslation();
  const requestChange = useContext(ChangeContext);
  const input = useRef<HTMLInputElement>(null);
  const changeButton = useRef<HTMLButtonElement>(null);
  const running = useRef<AbortController | null>(null);
  const [work, setWork] = useState<Work>({ kind: 'idle' });
  const statusId = useId();

  useEffect(() => () => running.current?.abort(), []);

  const editable = requestChange !== null && photosEnabled();
  const working = work.kind === 'working';

  const fail = (error: unknown) => {
    if (error instanceof DOMException && error.name === 'AbortError') return;
    const text =
      error instanceof PhotoFileError
        ? t(`tree.photo.errors.${error.problem}`)
        : error instanceof PhotoUploadError
          ? t('tree.photo.errors.upload')
          : t(errorMessageKey(error instanceof ApiError ? error : undefined));
    setWork({ kind: 'error', text });
  };

  const onFile = async (event: ChangeEvent<HTMLInputElement>) => {
    const file = event.target.files?.[0];
    event.target.value = '';
    if (file === undefined || requestChange === null) return;
    const problem = checkSource(file);
    if (problem !== null) {
      fail(new PhotoFileError(problem));
      return;
    }
    const controller = new AbortController();
    running.current = controller;
    setWork({ kind: 'working', fraction: 0 });
    try {
      const blob = await shrinkPhoto(file);
      if (blob.size > MAX_PHOTO_BYTES) throw new PhotoFileError('tooLarge');
      const target = await requestPhotoUpload(clanId, person.id);
      const photo = await uploadPhoto(
        target,
        blob,
        (fraction) => {
          setWork({ kind: 'working', fraction });
        },
        controller.signal,
      );
      if (controller.signal.aborted) return;
      setWork({ kind: 'idle' });
      requestChange({
        change: { kind: 'photo', personId: person.id, photo },
        focusFallback: () => changeButton.current,
      });
    } catch (error) {
      fail(error);
    } finally {
      if (running.current === controller) running.current = null;
    }
  };

  return (
    <section aria-label={t('tree.photo.section')} className="flex items-start gap-3">
      <ProfilePhoto person={person} />
      {editable ? (
        <div className="flex min-w-0 flex-col gap-2">
          <input
            ref={input}
            type="file"
            accept={PHOTO_TYPES.join(',')}
            className="sr-only"
            tabIndex={-1}
            aria-hidden="true"
            onChange={(event) => void onFile(event)}
          />
          <Button
            ref={changeButton}
            variant="secondary"
            disabled={working}
            aria-describedby={statusId}
            onClick={() => input.current?.click()}
          >
            <ImageUp {...ICON} />
            {t('tree.photo.change')}
          </Button>
          {person.photo ? (
            <Button
              variant="ghost"
              disabled={working}
              onClick={() =>
                requestChange({
                  change: { kind: 'photo', personId: person.id, photo: null },
                  focusFallback: () => changeButton.current,
                })
              }
            >
              <Trash2 {...ICON} />
              {t('tree.photo.remove')}
            </Button>
          ) : null}
          <p id={statusId} aria-live="polite" className="text-sm text-ink-muted">
            {working ? t('tree.photo.uploading') : ''}
          </p>
          {working ? (
            <progress
              max={1}
              value={work.fraction}
              aria-label={t('tree.photo.uploading')}
              className="w-full"
            />
          ) : null}
          {work.kind === 'error' ? (
            <p role="alert" className="text-sm text-danger">
              {work.text}
            </p>
          ) : null}
        </div>
```

- [ ] **Step 2: ADR 0011**

Read `docs/adr/0010-relate-rules-and-drag.md` for the format, then write `docs/adr/0011-photos-through-a-photo-store.md`:
- **Context:**
  - photos need a host with face-aware crops and signed uploads;
  - the API must stay the only place that names paths and holds the secret;
  - phone photos are 3–6 MB, against a 2 MB limit.
- **Decision:**
  1. Cloudinary through a small `PhotoStore` interface (sign, inspect, destroy, delete by prefix), using the official SDK, with a memory store for tests and e2e.
  2. The browser shrinks to 1600 px and WebP/JPEG at 0.85 before upload, then uploads straight to Cloudinary with a signature for one random path, using XHR for progress.
  3. A photo is an ordinary `updatePerson`. The server verifies every op that sets one (prefix, existence, version, 2 MB) before its transaction, and refuses with 422 even when photos are not set up, because the send queue retries 5xx.
  4. Photo changes run through the change runner, so they get the toast, Undo and history phrase.
  5. Deleting a clan deletes its prefix after the transaction; a failure is only logged.
- **Alternatives considered:**
  - uploading through the API (Render bandwidth and body limits);
  - unsigned upload presets (the browser could choose paths);
  - our own signing over REST without the SDK (more code to get right);
  - a manual crop tool (deferred; `g_face` first).
- **Consequences:**
  - one more API dependency;
  - old photos stay until the Phase 2 clean-up;
  - a Cloudinary outage fails photo saves with a retried 5xx, never other edits;
  - Netlify needs `VITE_CLOUDINARY_CLOUD_NAME`.

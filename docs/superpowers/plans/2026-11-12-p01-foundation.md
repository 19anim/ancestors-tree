# P1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the pnpm monorepo with a shared package, an Express API skeleton (route registry → OpenAPI, unified error handling, health route, API docs UI), a React web skeleton (Vietnamese i18n, typed API client, server-status widget), and CI — so that `pnpm check` is green locally and on GitHub Actions.

**Architecture:** `packages/shared` holds Zod schemas and the single `ERROR_CODES` table used by both apps. The API defines every route through `api.define(...)`, which validates input with Zod, optionally validates output, mounts the Express handler and registers the OpenAPI path in one call — so the API reference can never drift from the code. The web app talks to the API only through `apiRequest()`, which turns every failure into a typed `ApiError` whose `code` maps to a Vietnamese message.

**Tech Stack:** Node 24 (native TypeScript type stripping), pnpm 11 workspaces, TypeScript 6.0, Zod 4, Express 5, helmet, pino, @asteasolutions/zod-to-openapi 9, @scalar/express-api-reference, React 19, Vite 8, TanStack Query 5, i18next + react-i18next, Vitest 5 (projects), Testing Library, Supertest, ESLint 10 + typescript-eslint, Prettier, GitHub Actions.

**Spec:** [`docs/superpowers/specs/2026-11-11-ancestors-tree-design.md`](../specs/2026-11-11-ancestors-tree-design.md) — §4, §13.1, §14, §15. Roadmap: [`2026-11-12-roadmap.md`](2026-11-12-roadmap.md).

## Global Constraints

- Node `>=24.0.0`; package manager pinned with `"packageManager": "pnpm@11.17.0"`.
- TypeScript pinned to `~6.0.3` (typescript-eslint supports `typescript >=4.8.4 <6.1.0`; do not upgrade to 7.x).
- Everything in the repository is written in English (code, identifiers, comments, docs, commit messages). User-facing text lives only in `apps/web/src/locales/{vi,en}.json`; Vietnamese (`vi`) is the default language, `en` is the fallback; keys are English.
- `packages/shared` and `apps/api` run directly on Node (type stripping): relative imports **must** include the `.ts` extension; only erasable TypeScript syntax is allowed (no `enum`, `namespace`, or constructor parameter properties); use `import type` for type-only imports. `tsconfig.base.json` enforces this with `erasableSyntaxOnly` and `verbatimModuleSyntax`.
- Every API route is declared with `api.define(...)` (Task 5). Never call `router.get/post/...` directly for API routes.
- Every API error response has the shape `{ "error": { "code", "message", "details"? } }` with `code` from `ERROR_CODES`.
- Design docs are bilingual: any change to the spec updates both `*-design.md` and `*-design.vi.md` in the same commit.
- No visual design work in P1 (no CSS beyond browser defaults) — P2 owns the design system.
- Commit messages follow Conventional Commits (`feat:`, `test:`, `chore:`, `docs:`, `ci:`) and end with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` when committed by the agent.
- Before every commit run `pnpm format` so `pnpm format:check` stays green.

import { z } from 'zod';

interface ErrorCodeInfo {
  status: number;
  description: string;
  clientAction: string;
}

/** Single source of truth for API error codes. docs/error-codes.md is generated from this table. */
export const ERROR_CODES = {
  VALIDATION_ERROR: {
    status: 400,
    description: 'The request data failed validation; `details` lists each problem.',
    clientAction: 'Show the field errors next to the inputs.',
  },
  UNAUTHENTICATED: {
    status: 401,
    description: 'There is no valid session, or it has expired.',
    clientAction: 'Redirect to the sign-in page.',
  },
  FORBIDDEN: {
    status: 403,
    description: 'The user is signed in but their role does not allow this action.',
    clientAction: 'Show a "no permission" message; do not retry.',
  },
  NOT_FOUND: {
    status: 404,
    description: 'The requested resource or route does not exist.',
    clientAction: 'Show a not-found state.',
  },
  VERSION_CONFLICT: {
    status: 409,
    description:
      "The tree changed after the client's baseVersion; newer operations must be fetched first.",
    clientAction: 'Fetch missing operations, rebase pending changes, then resend.',
  },
  RULE_VIOLATION: {
    status: 422,
    description: 'The change breaks a genealogy business rule enforced by applyOp.',
    clientAction: 'Show the reason and discard the change.',
  },
  RATE_LIMITED: {
    status: 429,
    description: 'Too many requests in a short time window.',
    clientAction: 'Wait, then retry with exponential backoff.',
  },
  INTERNAL_ERROR: {
    status: 500,
    description: 'An unexpected server error occurred; details are only in the server logs.',
    clientAction: 'Show a generic error with a retry button.',
  },
} as const satisfies Record<string, ErrorCodeInfo>;

export type ErrorCode = keyof typeof ERROR_CODES;

export const ERROR_CODE_LIST = Object.keys(ERROR_CODES) as [ErrorCode, ...ErrorCode[]];

export const ErrorDetailSchema = z.object({
  path: z.string(),
  message: z.string(),
});

export const ApiErrorBodySchema = z.object({
  error: z.object({
    code: z.enum(ERROR_CODE_LIST),
    message: z.string(),
    details: z.array(ErrorDetailSchema).optional(),
  }),
});

export type ErrorDetail = z.infer<typeof ErrorDetailSchema>;
export type ApiErrorBody = z.infer<typeof ApiErrorBodySchema>;
```

- [ ] **Step 3: Implement the renderer**

`packages/shared/src/errors-doc.ts`:

```ts
import { ERROR_CODE_LIST, ERROR_CODES } from './errors.ts';

const escapeCell = (text: string): string => text.replaceAll('|', '\\|');

export function renderErrorCodesMarkdown(): string {
  const rows = ERROR_CODE_LIST.map((code) => {
    const info = ERROR_CODES[code];
    return `| \`${code}\` | ${info.status} | ${escapeCell(info.description)} | ${escapeCell(info.clientAction)} |`;
  });

  return [
    '# API error codes',
    '',
    '> Generated from `packages/shared/src/errors.ts` by `pnpm docs:errors`. Do not edit by hand.',
    '',
    'Every API error response has this shape:',
    '',
    '```json',
    '{ "error": { "code": "VALIDATION_ERROR", "message": "Invalid request body", "details": [{ "path": "body.name", "message": "Too small" }] } }',
    '```',
    '',
    '| Code | HTTP status | Meaning | Client handling |',
    '| --- | --- | --- | --- |',
    ...rows,
    '',
  ].join('\n');
}
```

const target = fileURLToPath(new URL('../../../docs/error-codes.md', import.meta.url));

  console.log('docs/error-codes.md is up to date.');

  console.log('Wrote docs/error-codes.md');
}

export class AppError extends Error {
  readonly code: ErrorCode;
  readonly status: number;
  readonly details: ErrorDetail[] | undefined;

  constructor(code: ErrorCode, message: string, details?: ErrorDetail[]) {
    super(message);
    this.name = 'AppError';
    this.code = code;
    this.status = ERROR_CODES[code].status;
    this.details = details;
  }
}

export function zodIssuesToDetails(
  issues: readonly { path: readonly PropertyKey[]; message: string }[],
  prefix: string,
): ErrorDetail[] {
  return issues.map((issue) => ({
    path: [prefix, ...issue.path.map(String)].join('.'),
    message: issue.message,
  }));

import type { ApiErrorBody } from '@ancestors-tree/shared';
import type { ErrorRequestHandler } from 'express';
import type { Logger } from 'pino';
import { AppError } from './AppError.ts';

function isMalformedJsonError(err: unknown): boolean {
  return (
    typeof err === 'object' &&
    err !== null &&
    'type' in err &&
    (err as { type: unknown }).type === 'entity.parse.failed'
  );
}

function toAppError(err: unknown, logger: Logger): AppError {
  if (err instanceof AppError) return err;
  if (isMalformedJsonError(err)) return new AppError('VALIDATION_ERROR', 'Malformed JSON body');
  logger.error({ err }, 'Unhandled error');
  return new AppError('INTERNAL_ERROR', 'Unexpected server error');
}

export function createErrorHandler(logger: Logger): ErrorRequestHandler {
  return (err, _req, res, next) => {
    if (res.headersSent) {
      next(err);
      return;
    }
    const appError = toAppError(err, logger);
    const body: ApiErrorBody = {
      error: {
        code: appError.code,
        message: appError.message,
        ...(appError.details ? { details: appError.details } : {}),
      },
    };
    res.status(appError.status).json(body);
  };
}

```ts
import { OpenAPIRegistry, type RouteConfig } from '@asteasolutions/zod-to-openapi';
import { ApiErrorBodySchema } from '@ancestors-tree/shared';
import { Router, type Request, type Response } from 'express';
import type { z } from 'zod';
import { AppError, zodIssuesToDetails } from './AppError.ts';

export type HttpMethod = 'get' | 'post' | 'put' | 'patch' | 'delete';

export interface HandlerResult {
  status: number;
  body?: unknown;
}

export interface RouteResponse {
  description: string;
  schema?: z.ZodType;
}

export interface HandlerContext<P, Q, B> {
  params: P;
  query: Q;
  body: B;
  req: Request;
  res: Response;
}

export interface RouteDefinition<
  P extends z.ZodObject = z.ZodObject,
  Q extends z.ZodObject = z.ZodObject,
  B extends z.ZodType = z.ZodType,
> {
  method: HttpMethod;
  /** Express-style path relative to /api, e.g. "/clans/:id". */
  path: string;
  summary: string;
  tags: string[];
  request?: { params?: P; query?: Q; body?: B };
  responses: Record<number, RouteResponse>;
  handler: (
    ctx: HandlerContext<z.output<P>, z.output<Q>, z.output<B>>,
  ) => HandlerResult | Promise<HandlerResult>;
}

export interface RegisteredRoute {
  method: HttpMethod;
  path: string;
  openApiPath: string;
}

export interface RouteRegistryOptions {
  /** Validate handler output against the declared response schema (on outside production). */
  validateResponses: boolean;
}

type RequestPart = 'params' | 'query' | 'body';

export function toOpenApiPath(path: string): string {
  return path.replace(/:([A-Za-z0-9_]+)/g, '{$1}');
}

function parsePart(schema: z.ZodType | undefined, value: unknown, part: RequestPart): unknown {
  if (!schema) return part === 'body' ? undefined : {};
  const parsed = schema.safeParse(value ?? {});
  if (!parsed.success) {
    throw new AppError(
      'VALIDATION_ERROR',
      `Invalid request ${part}`,
      zodIssuesToDetails(parsed.error.issues, part),
    );
  }
  return parsed.data;
}

function assertResponseMatches(
  route: Pick<RouteDefinition, 'method' | 'path' | 'responses'>,
  result: HandlerResult,
): void {
  const label = `${route.method.toUpperCase()} ${route.path}`;
  const declared = route.responses[result.status];
  if (!declared) {
    throw new Error(`${label} returned undeclared status ${result.status}`);
  }
  if (declared.schema) {
    const parsed = declared.schema.safeParse(result.body);
    if (!parsed.success) {
      throw new Error(`${label} response does not match its schema: ${parsed.error.message}`);
    }
  }
}

function toOpenApiResponses(responses: Record<number, RouteResponse>): RouteConfig['responses'] {
  const documented: RouteConfig['responses'] = {};
  for (const [status, response] of Object.entries(responses)) {
    documented[status] = {
      description: response.description,
      ...(response.schema ? { content: { 'application/json': { schema: response.schema } } } : {}),
    };
  }
  documented.default = {
    description: 'Error response (see docs/error-codes.md)',
    content: { 'application/json': { schema: ApiErrorBodySchema } },
  };
  return documented;
}

export function createRouteRegistry(options: RouteRegistryOptions) {
  const router = Router();
  const openApi = new OpenAPIRegistry();
  const routes: RegisteredRoute[] = [];

  openApi.register('ApiErrorBody', ApiErrorBodySchema);

  function define<P extends z.ZodObject, Q extends z.ZodObject, B extends z.ZodType>(
    route: RouteDefinition<P, Q, B>,
  ): void {
    if (routes.some((r) => r.method === route.method && r.path === route.path)) {
      throw new Error(`Route already defined: ${route.method.toUpperCase()} ${route.path}`);
    }
    const openApiPath = toOpenApiPath(route.path);
    routes.push({ method: route.method, path: route.path, openApiPath });

    const { params, query, body } = route.request ?? {};
    openApi.registerPath({
      method: route.method,
      path: openApiPath,
      summary: route.summary,
      tags: route.tags,
      request: {
        ...(params ? { params } : {}),
        ...(query ? { query } : {}),
        ...(body
          ? { body: { required: true, content: { 'application/json': { schema: body } } } }
          : {}),
      },
      responses: toOpenApiResponses(route.responses),
    });

    router[route.method](route.path, async (req, res) => {
      const result = await route.handler({
        params: parsePart(params, req.params, 'params') as z.output<P>,
        query: parsePart(query, req.query, 'query') as z.output<Q>,
        body: parsePart(body, req.body, 'body') as z.output<B>,
        req,
        res,
      });
      if (options.validateResponses) assertResponseMatches(route, result);
      if (result.body === undefined) {
        res.status(result.status).end();
      } else {
        res.status(result.status).json(result.body);
      }
    });
  }

  return { router, openApi, routes: routes as readonly RegisteredRoute[], define };
}

export type RouteRegistry = ReturnType<typeof createRouteRegistry>;
```

import type { ErrorCode } from '@ancestors-tree/shared';

/** Codes produced by the client itself, never sent by the API. */
export const CLIENT_ONLY_ERROR_CODES = ['NETWORK_ERROR', 'INVALID_RESPONSE'] as const;

export type ClientErrorCode = ErrorCode | (typeof CLIENT_ONLY_ERROR_CODES)[number];

export class ApiError extends Error {
  readonly code: ClientErrorCode;
  readonly status: number;

  constructor(code: ClientErrorCode, message: string, status: number) {
    super(message);
    this.name = 'ApiError';
    this.code = code;
    this.status = status;
  }
}

/** Translation key for any thrown value; unknown errors fall back to INTERNAL_ERROR. */
export function errorMessageKey(error: unknown): `errors.${ClientErrorCode}` {
  return `errors.${error instanceof ApiError ? error.code : 'INTERNAL_ERROR'}`;
}

- [ ] **Step 3: Implement `apiClient.ts`**

```ts
import { ApiErrorBodySchema } from '@ancestors-tree/shared';
import type { z } from 'zod';
import { ApiError } from './apiError';

export async function apiRequest<T>(
  path: string,
  schema: z.ZodType<T>,
  init: RequestInit = {},
): Promise<T> {
  const headers = new Headers(init.headers);
  headers.set('Accept', 'application/json');

  let response: Response;
  try {
    response = await fetch(`/api${path}`, { ...init, headers, credentials: 'include' });
  } catch {
    throw new ApiError('NETWORK_ERROR', 'Network request failed', 0);
  }

  const payload: unknown = await response.json().catch(() => undefined);

  if (!response.ok) {
    const apiError = ApiErrorBodySchema.safeParse(payload);
    if (apiError.success) {
      const { code, message } = apiError.data.error;
      throw new ApiError(code, message, response.status);
    }
    throw new ApiError(
      'INVALID_RESPONSE',
      `Unexpected error response (HTTP ${response.status})`,
      response.status,
    );
  }

  const parsed = schema.safeParse(payload);
  if (!parsed.success) {
    throw new ApiError(
      'INVALID_RESPONSE',
      'Response did not match the expected schema',
      response.status,
    );
  }
  return parsed.data;
}

# ADR 0001: Monorepo with a shared package

- Status: Accepted
- Date: 2026-11-12

## Context

The web app and the API must agree on data shapes (Zod schemas), business rules (`applyOp`), the lunar calendar and error codes. Keeping them in separate repositories would force copying code or publishing an npm package on every change.

## Decision

Use one pnpm workspace with `apps/web`, `apps/api`, `apps/cron-worker` and `packages/shared`. Both apps import `@ancestors-tree/shared` directly from source. Each app is deployed separately (Netlify base directory `apps/web`, Render root directory `apps/api`).

## Consequences

- A change to a schema is one commit and one PR, and TypeScript reports mismatches on both sides immediately.
- CI runs for the whole repository; deploy hooks must be scoped to the folders each app depends on.
```

`docs/adr/0002-run-typescript-natively-on-node.md`:

```markdown
# ADR 0002: Run the API's TypeScript natively on Node 24

- Status: Accepted
- Date: 2026-11-12

## Context

Node 24 strips TypeScript types natively. A separate compile step (tsc emit, tsup, esbuild) adds configuration and a `dist/` folder that can drift from the sources.

## Decision

`apps/api` and `packages/shared` run as `.ts` files directly (`node src/server.ts`, `node --watch` in development). TypeScript is used only for type checking (`tsc --noEmit`). `tsconfig.base.json` enables `erasableSyntaxOnly`, `verbatimModuleSyntax` and `allowImportingTsExtensions`.

## Consequences

- Relative imports must include the `.ts` extension.
- Only erasable syntax is allowed: no `enum`, `namespace` or constructor parameter properties (use `as const` objects and explicit fields instead).
- The workspace package resolves through a symlink to `packages/shared`, which is outside `node_modules`, so Node strips its types too (verified on Node 24.12).
- TypeScript stays on 6.0.x until typescript-eslint supports 7.x.
```

`docs/adr/0003-route-registry-as-openapi-source.md`:

```markdown
# ADR 0003: Route registry as the single source of the OpenAPI document

- Status: Accepted
- Date: 2026-11-12

## Context

The spec requires 100% of API routes to appear in the generated API reference (success criterion S8). Inspecting Express's internal router stack to compare routes against the document is fragile across Express versions.

## Decision

Every API route is declared once with `api.define({ method, path, request, responses, handler })`. That single call validates params/query/body with Zod, optionally validates the response outside production, mounts the Express handler and registers the OpenAPI path. A test asserts that the generated document contains exactly the registered routes.

## Consequences

- Undocumented routes cannot exist as long as routes are not added with `router.get/post/...` directly (enforced in code review and CONTRIBUTING.md).
- Handlers return `{ status, body }` instead of writing to `res`, which also makes them easier to test.
```
